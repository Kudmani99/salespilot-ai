# SalesPilot AI

A prototype toolkit for small business owners who need help with sales and marketing. It generates cold emails, social media posts and follow-up sequences from your business details, and has a practice mode for handling common objections like "it's too expensive."

Everything runs in the browser and saves to local storage, so there is no account or backend. The content comes from templates for now. Hooking it up to a real AI model is the next step.

**Built with** Next.js 16, React 19, TypeScript, Tailwind CSS

**Run it**
```bash
npm install
npm run dev   # http://localhost:3005
```
